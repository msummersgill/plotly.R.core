# Specify attributes of selection traces

By default the name of the selection trace derives from the selected
values.

## Usage

``` r
attrs_selected(opacity = 1, ...)
```

## Arguments

- opacity:

  a number between 0 and 1 specifying the overall opacity of the
  selected trace

- ...:

  other trace attributes attached to the selection trace.

## Value

A list of trace attributes.
