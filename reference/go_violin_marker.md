# Violin marker objects

The object for the `marker` of a violin trace
([`go_violin()`](https://msummersgill.github.io/plotly.R.core/reference/go_violin.md)).
`go_violin_marker()` creates one, with exactly its properties; a named
list with the same properties works too.

## Usage

``` r
go_violin_marker(
  arg = NULL,
  ...,
  angle = NULL,
  color = NULL,
  line = NULL,
  opacity = NULL,
  outliercolor = NULL,
  size = NULL,
  symbol = NULL,
  skip_invalid = FALSE
)
```

## Arguments

- arg:

  Optional named list, or graph object of the same type, to initialise
  properties from. Named arguments take precedence.

- ...:

  Not used: properties must be named in full.

- angle:

  Sets the marker angle in respect to \`angleref\`. Angle in degrees.

- color:

  Sets the marker color. It accepts either a specific color or an array
  of numbers that are mapped to the colorscale relative to the max and
  min values of the array or relative to \`marker.cmin\` and
  \`marker.cmax\` if set. Color: a CSS color string or R color name.

- line:

  A
  [`go_violin_marker_line()`](https://msummersgill.github.io/plotly.R.core/reference/go_violin_marker_line.md)
  object or named list, with properties `color`, `outliercolor`,
  `outlierwidth` and `width` (see
  [`go_violin_marker_line()`](https://msummersgill.github.io/plotly.R.core/reference/go_violin_marker_line.md)).

- opacity:

  Sets the marker opacity. Number in the interval \[0, 1\].

- outliercolor:

  Sets the color of the outlier sample points. Color: a CSS color string
  or R color name.

- size:

  Sets the marker size (in px). Number in the interval \[0, Inf\].

## Value

A `go_violin_marker` object (a named list).

## Details

Nested objects are named lists, or objects of the constructors their
arguments name. Every property is checked against the plotly.js schema
when the object is created or modified. A property may be a one-sided
formula (`color = ~col`): it is kept, and evaluated in the data (then
checked) when its trace is added to a figure with `add_<trace>()` or
[`add_trace()`](https://msummersgill.github.io/plotly.R.core/reference/add_traces.md).

## Examples

``` r
mtcars |>
  go_figure() |>
  add_violin(
    x = ~factor(cyl),
    y = ~mpg,
    marker = go_violin_marker(color = "red")
  )
```
