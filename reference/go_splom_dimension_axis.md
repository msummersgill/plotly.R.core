# Splom dimension axis objects

The object for the `dimension.axis` of a splom trace
([`go_splom_dimension()`](https://msummersgill.github.io/plotly.R.core/reference/go_splom_dimension.md)).
`go_splom_dimension_axis()` creates one, with exactly its properties; a
named list with the same properties works too.

## Usage

``` r
go_splom_dimension_axis(
  arg = NULL,
  ...,
  matches = NULL,
  type = NULL,
  skip_invalid = FALSE
)
```

## Arguments

- arg:

  Optional named list, or graph object of the same type, to initialise
  properties from. Named arguments take precedence.

- ...:

  Not used: properties must be named in full.

- matches:

  Determines whether or not the x & y axes generated by this dimension
  match. Equivalent to setting the \`matches\` axis attribute in the
  layout with the correct axis id. Logical.

- type:

  Sets the axis type for this dimension's generated x and y axes. Note
  that the axis \`type\` values set in layout take precedence over this
  attribute. One of `"linear"`, `"log"`, `"date"`, `"category"`.

- skip_invalid:

  If `TRUE`, silently drop invalid properties instead of raising an
  error.

## Value

A `go_splom_dimension_axis` object (a named list).

## Details

Nested objects are named lists, or objects of the constructors their
arguments name. Every property is checked against the plotly.js schema
when the object is created or modified. A property may be a one-sided
formula (`color = ~col`): it is kept, and evaluated in the data (then
checked) when its trace is added to a figure with `add_<trace>()` or
[`add_trace()`](https://msummersgill.github.io/plotly.R.core/reference/add_traces.md).

## Examples

``` r
go_splom(
  dimensions = list(go_splom_dimension(
    axis = go_splom_dimension_axis()
  ))
)
#> <go_splom>
#> {
#>   "type": "splom",
#>   "dimensions": [
#>     {
#>       "axis": {
#> 
#>       }
#>     }
#>   ]
#> }
#> 
```
